# 超智能 SUPER INTELLIGENCE — 官方網站

超智能股份有限公司（SUPER INTELLIGENCE Co., Ltd.）的官方形象網站。
純靜態、單一 HTML 檔（`index.html`），無建置流程、無外部 JS 框架，開檔即用。

## 特色

- **三語切換**：繁體中文／English／日本語，右上角快速切換
  - 支援網址參數直接指定語言：`?lang=zh`、`?lang=en`、`?lang=ja`
  - 首次進站依瀏覽器語言自動偵測
- **三組幾何 Canvas 動畫**，動態詮釋三大業務主軸：
  - 企業 AI 流程再造 —「亂流 → 秩序」：混亂任務流穿過 AI 核心，收束為平行協作流
  - 產業 AI 智慧作業系統 —「散點 → 晶格」：散落知識點結晶成有序智慧網格
  - 語氣靈 —「軌道 × 核心」：記憶、情境、關係、行動環繞人格核心運行
- **RWD 響應式**：手機／iPad／桌機皆已驗證
- **低延遲、低算力**：零圖片、零外部函式庫；靜態圖層離屏快取、捲出視窗與背景分頁自動暫停、Hero 鎖 30fps、支援 `prefers-reduced-motion`
